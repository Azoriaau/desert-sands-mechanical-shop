# Desert Sands Mechanical – Shop

Shopify Hydrogen storefront for [shop.desertsandsmechanical.com](https://shop.desertsandsmechanical.com).
It is built to look like one site with [desertsandsmechanical.com](https://www.desertsandsmechanical.com):
same header, footer, brand tokens and fonts, with every nav item except "Shop"
linking back to the main site.

## Stack

- [Shopify Hydrogen](https://shopify.dev/docs/storefronts/headless/hydrogen) on React Router 7 (framework mode), hosted on Oxygen
- Tailwind v4, configured in `app/styles/tailwind.css` (brand tokens, buttons, cards)
- Oswald and Inter self-hosted via Fontsource
- Storefront API types generated by `npm run codegen` into `storefrontapi.generated.d.ts`

## Local development

```bash
npm install
npm run dev
```

Until the project is linked to the store, the dev server uses Shopify's
[mock.shop](https://mock.shop) sample catalogue and shows a "Preview build" banner.

Other scripts: `npm run build`, `npm run preview`, `npm run lint`, `npm run typecheck`, `npm run codegen`.

## Linking the real store (one-off)

1. In Shopify admin, install the **Hydrogen** sales channel.
2. Run `npx shopify hydrogen link`, log in, pick the Desert Sands Mechanical store and create (or choose) the Hydrogen storefront.
3. Run `npx shopify hydrogen env pull` to write the Storefront API tokens into `.env`. Never commit `.env`; see `.env.example`.
4. Restart `npm run dev`. The banner disappears once `PUBLIC_STORE_DOMAIN` is set.

## Deploying

- `npx shopify hydrogen deploy` publishes to Oxygen, or connect the GitHub repo in the Hydrogen channel for automatic deploys on push.
- Secrets (private Storefront token, session secret) live in the Hydrogen channel's environment settings, not in the repo.
- Cut-over: in admin, move `shop.desertsandsmechanical.com` from the Online Store channel to the Hydrogen storefront's domains. The theme keeps serving until then.

## Keeping in step with the main site

| Shop file | Main site file |
| --- | --- |
| `app/lib/site.ts` (business details, nav) | `lib/site.ts` |
| `app/styles/tailwind.css` (`@theme` tokens, `.btn`, `.card`, `.eyebrow`) | `app/globals.css` |
| `app/components/Header.tsx`, `Footer.tsx`, `Logo.tsx`, `icons.tsx`, `PageHero.tsx`, `CTABand.tsx` | `components/` |

## Customer accounts

The `/account` routes from the Hydrogen skeleton are kept but not linked from the
navigation. They need the Customer Account API enabled for the storefront in
Shopify admin before they work; see the
[Hydrogen docs](https://shopify.dev/docs/storefronts/headless/building-with-the-customer-account-api/hydrogen).
